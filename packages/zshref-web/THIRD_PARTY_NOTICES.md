`zshref-web` ships third-party material in its built site (`build/`): data
derived from the zsh documentation, and bundled npm packages and fonts under
their own licences. The build writes the npm packages' licences to
`THIRD_PARTY_LICENSES.md`; this file covers the rest.

zsh documentation
-----------------

The search index carries text derived from the zsh documentation sources
(tag `zsh-5.9`), under the zsh licence.
Provenance and full licence text:
`packages/zsh-lexicon/src/data/zsh-docs/THIRD_PARTY_NOTICES.md`.

Embedding model
---------------

`BAAI/bge-small-en-v1.5` (MIT) is not bundled: the browser downloads it at
runtime from the Hugging Face Hub. The shipped search vectors
(`search-vectors.bin`) are its output.

ONNX Runtime Web
----------------

`onnxruntime-web` (MIT, Microsoft) runs the model in the browser. Its
JavaScript, with `onnxruntime-common`'s, is bundled; its WebAssembly binary
and loader are downloaded at runtime from jsDelivr, at the version
`@huggingface/transformers` pins. Neither npm package carries a licence file;
see "MIT" below.

Syntax highlighting
-------------------

Shiki's packages embed upstream material:

- the shell grammar, from VS Code (MIT)
- the GitHub light and dark themes, from Primer's `github-vscode-theme` (MIT)
- the Oniguruma regex engine as WebAssembly, from `vscode-oniguruma` (MIT),
  a build of Oniguruma (BSD-2-Clause)

Fonts
-----

Inter and JetBrains Mono are bundled as `.woff2` (`@fontsource-variable/*`),
under the SIL Open Font License 1.1.
