This repository is primarily MIT-licensed original work by the repository
author(s), but it also contains copied third-party material with separate
notices kept close to the copied files.

Package-local notices are tracked beside package roots and vendored material.
To list them: `git ls-files '*THIRD_PARTY_NOTICES.md'`.

Current copied third-party material:

- zsh documentation sources vendored under `packages/zsh-core/src/data/zsh-docs/`
- the shell TextMate grammar vendored under
  `packages/vscode-better-zsh/syntaxes/shell-unix-bash.tmLanguage.json`

For release artifacts, see the package-local notice files and the copies
that are shipped with each package.
